## Supporting files

- `Report.tex` — the report source (hand-maintained; see "Rebuilding" below)
- `Cellular_PT.pkt` — Cisco Packet Tracer 8.x topology used in Appendix D
- `results.json` — computed numbers from `analysis.py`
- `figures/` — 10 figures (coverage maps, BER curves, handoff traces, delay profile,
  capacity, C/I, and the Packet Tracer topology capture)
- `code/analysis.py` — link budgets, Monte-Carlo coverage, BER simulation, handover
  simulation, Erlang-B, capacity. Generates every figure in `figures/`.
- `code/hardware.py` — the BOM with vendor links and cost buckets
- `code/build_report.py` — typesets a report from `results.json` via `report_template.tex`

## Rebuilding the PDF

```bash
cd Submission
pdflatex Report.tex && pdflatex Report.tex
```

## Important: `Report.tex` is no longer generated

`Report.tex` used to be regenerated by `code/build_report.py`. It is now hand-maintained
and has diverged from `results.json` and `report_template.tex` in several places, most
importantly the coverage results and the target-compliance verdicts.

Running `python code/build_report.py` will **overwrite `Report.tex`** and discard those
corrections. Only re-run the generator if you intend to rebuild from the template, and
diff the result before committing it.

`code/analysis.py` is still safe to re-run: it recomputes numbers and regenerates figures
but does not touch `Report.tex`.

## Packet Tracer appendix note

The `.pkt` is supplied as a companion file, not embedded in the PDF. Two honest
qualifications are recorded in Appendix D.2: the red link markers on `IP-HOSP-01`,
`IP-HOSP-02` and `IP-CLINIC-01` mean those access links are **down** in the saved state,
so protected-building continuity is topology intent rather than a passing test; and the
BOM small cells appear as Wi-Fi access points because Packet Tracer has no LTE small cell.
No BER, SINR, reuse or Erlang result in the report is derived from the simulator.
